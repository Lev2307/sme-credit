# mocks

Отдельный сервис на Django + DRF, который изображает внешние источники данных:

| Эндпоинт | Что изображает |
|---|---|
| `GET /egrul/{inn}` | ЕГРЮЛ/ЕГРИП |
| `GET /transparent-business/{inn}` | «Прозрачный бизнес» ФНС |
| `GET /bki/{inn}` | Бюро кредитных историй |

Каждый запрос должен нести заголовок `X-Api-Key` с ключом из `MOCKS_API_KEY`. Без ключа ответ — `403`, на неизвестный ИНН — `404`. Swagger UI (`/docs/`) и схема (`/schema/`) открыты без ключа. Чтобы отправлять запросы прямо из Swagger, нажмите Authorize и введите ключ.

## Данные

Базы у сервиса нет. Компании лежат в [data/companies.json](data/companies.json), ключ — ИНН, внутри три раздела по источникам. Файл читается заново на каждый запрос, поэтому правки видны сразу, без перезапуска. Поле `scenario` — пояснение для людей, наружу оно не отдаётся.

Все компании синтетические. ИНН и ОГРН выдуманы, но контрольные суммы у них правильные. Каждая компания ведёт заявку в свой исход:

| ИНН | Компания | Исход | Почему |
|---|---|---|---|
| `9901000010` | ООО «Надёжная пекарня» | Одобрение | Больше 3 лет, без долгов и просрочек, нагрузка низкая |
| `990100000285` | ИП Дуров П. А. («Амбициозная») | Контрпредложение | Чистая история, но просит много относительно выручки |
| `9901000034` | ООО «Неточная отделка» | Дозапрос | Выручка по отчётности около 12 млн. В анкете нужно указать больше 15,4 млн |
| `990100000422` | ИП Светлов Н. О. («Пограничная») | Андеррайтер | Истории нет, налоговый долг больше 10% месячной выручки, класс не выше C |
| `9901000059` | ООО «Проблемная логистика» | Отказ | Ликвидируется, есть текущая просрочка |
| `9901000066` | ООО «Капризная мастерская» | Андеррайтер (`SOURCE_UNAVAILABLE`) | БКИ отвечает `503` |

Сбой БКИ задаётся полем `bki.failure`:

- `null` — нормальный ответ;
- `"error"` — сразу `503`;
- `"timeout"` — ответ приходит через `MOCKS_BKI_DELAY_SECONDS` секунд (по умолчанию 5), когда бэкенд уже перестал ждать.

## Структура

```
mocks/
├── config/                     # settings, urls
├── data/companies.json         # синтетические компании
├── conftest.py                 # общие фикстуры тестов и ИНН компаний
└── apps/
    ├── common/                 # чтение JSON, проверка API-ключа, справочники, тесты доступа и данных
    ├── egrul/                  # serializers.py, views.py, urls.py, tests/
    ├── transparent_business/
    └── bki/
```

Моделей, миграций и админки нет: данные лежат в JSON-файле. Вьюхи — `RetrieveAPIView` из DRF, сериализаторы задают формат ответа и OpenAPI-схему.

## Локальный запуск

У моков своё окружение и свой `uv.lock`. Из папки `mocks`:

```bash
uv sync
uv run python manage.py runserver 8090
uv run pytest
```
