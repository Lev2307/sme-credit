# mocks

Сервис на FastAPI, который изображает внешние источники данных:

| Эндпоинт | Что изображает |
|---|---|
| `GET /egrul/{inn}` | ЕГРЮЛ/ЕГРИП |
| `GET /transparent-business/{inn}` | «Прозрачный бизнес» ФНС |
| `GET /bki/{inn}` | Бюро кредитных историй |

Данные лежат в `data/companies.json`, ключ — ИНН. Все компании синтетические, каждая ведёт заявку в свой исход: одобрение, контрпредложение, дозапрос, андеррайтер, отказ. Список тестовых компаний в [docs/02-process.md](../docs/02-process.md#тестовые-компании).

Контракты доступны в Swagger UI по адресу http://localhost:8090/docs после запуска.
